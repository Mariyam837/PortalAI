# PortalAI

## About the Project

PortalAI is a Flutter application currently under development. This repository contains the source code and project files for the application.

## Getting Started

### Prerequisites

Before running the project, install:

* [Flutter SDK](https://docs.flutter.dev/get-started/install)
* [Git](https://git-scm.com/downloads)
* [Visual Studio Code](https://code.visualstudio.com/) with the Flutter and Dart extensions

### Setup Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/Mariyam837/PortalAI
   ```

2. Open the project folder in VS Code.

3. Install the project dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## Project Structure

* `lib/` — Application source code.
* `test/` — Automated tests.
* `android/` — Android platform files.
* `ios/` — iOS platform files.
* `web/` — Web platform files.
* `windows/` — Windows platform files.
* `pubspec.yaml` — Project configuration and dependencies.
