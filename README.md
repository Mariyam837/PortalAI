# PortalAI

## About the Project

PortalAI is a Flutter application currently under development. This repository contains the source code and project files for the application.

Our current development focus is building a clean, modern user interface with a neumorphic design style, featuring soft shadows, rounded elements, and a pastel colour palette.

## Technology Stack

- **Framework:** Flutter
- **Programming Language:** Dart
- **Code Editor:** Visual Studio Code
- **Version Control:** Git and GitHub

## UI Dependencies

PortalAI currently uses the following packages for its UI development:

- [`flutter_neumorphic_plus`](https://pub.dev/packages/flutter_neumorphic_plus) — for neumorphic UI components and styling.
- [`inner_shadow_flutter`](https://pub.dev/packages/inner_shadow_flutter) — for inner-shadow effects.

## Getting Started

### Prerequisites

Before running the project, install:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Git](https://git-scm.com/downloads)
- [Visual Studio Code](https://code.visualstudio.com/) with the Flutter and Dart extensions

### Setup Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/Mariyam837/PortalAI.git
   ```

2. Open the cloned `PortalAI` folder in VS Code.

3. Install the project dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application in Google Chrome:

   ```bash
   flutter run -d chrome
   ```

   Alternatively, use `flutter run` to select another available device.
